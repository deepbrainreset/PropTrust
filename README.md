# PropTrust

MVP inicial de marketplace PropTech AI-first para Argentina.

## Stack
- React + TypeScript + Vite
- UI responsive
- Datos demo claramente identificados
- Preparado para Firebase Auth / Firestore / Storage / Cloud Functions

## Ejecutar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Próxima iteración
1. Firebase Auth y RBAC: BUYER, OWNER, AGENT, AGENCY, ADMIN, SUPER_ADMIN.
2. Firestore + Storage.
3. Publicación real de propiedades.
4. Perfiles profesionales y verificación.
5. Trust Score y Property Score auditables.
6. Marketplace inverso de captación.
7. CRM y agenda.
8. Gemini para descripción, clasificación y detección de anomalías.
9. SEO dinámico y rutas indexables.
10. Integración de pagos en fase posterior.

> Importante: ninguna propiedad, verificación o score de esta demo representa información real.
